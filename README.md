# Customer-Churn-ML-Model-and-Power-BI-Analysis-Package
📊 Customer Churn Analytics & Prediction Project
🚀 Overview

This project delivers an end-to-end customer churn analytics solution, combining machine learning, data modeling, and Power BI dashboards to transform raw data into actionable business insights.

It enables organisations to move from reactive churn reporting to proactive, data-driven retention strategies.

🎯 Key Features
📈 Interactive Power BI Dashboard
Executive overview of churn metrics
Risk segmentation (Low → Very High)
Customer-level retention insights
🤖 Machine Learning Model
Predicts churn probability for each customer
Generates risk bands and retention priorities
Provides interpretable feature importance
📋 Retention Action Framework
Identifies Top 100 high-risk customers
Enables targeted intervention strategies
📄 Professional Documentation
Business analysis report (stakeholder-ready)
Technical ML whitepaper (model explanation)
🧠 Business Problem

Customer churn significantly impacts revenue and growth.
This project answers:

What drives customer churn?
Which customers are most at risk?
How should retention efforts be prioritised?
📊 Dashboard Pages
1️⃣ Executive Overview
Key KPIs (Total Customers, Churn, Risk)
Churn by contract and service type
Risk distribution across customer base
2️⃣ Retention Action
High-risk customer segmentation
Top 100 customers requiring intervention
Operational insights for retention teams
3️⃣ ML Model Insights
Feature importance (key churn drivers)
Model interpretability and transparency
🤖 Machine Learning Approach
Data preprocessing & feature engineering
One-hot encoding of categorical variables
Train/test split with stratification
Model comparison (Logistic Regression, Random Forest, Gradient Boosting)
Final model: Random Forest
Outputs:
Churn probability (0–100%)
Risk bands (Low → Very High)
Retention priority classification
